# Brasshaven

**Forge an industrial empire in a world powered by steam, gears, and ambition.**

Brasshaven is a steampunk city-building tycoon game where every resource matters. Build factories, manage production chains, research advanced technologies, expand your territory, launch airship expeditions, and respond to unexpected events as your city grows into an industrial powerhouse.

Built for **SBU Hacks 2026**, Brasshaven combines resource management, strategic expansion, and event-driven decisions in a world inspired by Victorian-era industrial machinery.

## Gameplay

- **Build your city:** Construct and upgrade industrial buildings to expand your production capabilities.
- **Manage resources:** Balance Brass Coins, Gears, Steam, Oil, Research, and Aether Crystals.
- **Develop your industry:** Connect buildings and production systems to support your growing economy.
- **Research new technology:** Unlock upgrades, advanced buildings, and new opportunities.
- **Expand your territory:** Unlock additional plots and plan your city's growth.
- **Explore the world:** Send airships on expeditions for valuable resources and rewards.
- **Complete objectives:** Fulfill contracts, achieve milestones, and earn rewards.
- **Respond to events:** Make decisions during emergencies, supply disruptions, and other city events.
- **Build toward victory:** Develop the technology and industry needed to complete the Great Engine.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm, included with Node.js

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/sin-squared/SBU-Hacks-2026.git
cd SBU-Hacks-2026
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open the local URL printed in your terminal.

## Development and Testing

Run the project's test suite:

```bash
npm test
```

Check TypeScript types:

```bash
npx tsc --noEmit
```

Create a production build:

```bash
npm run build
```

Use the commands supported by the current project configuration if any of these scripts differ.
